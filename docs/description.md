# Описание проекта

## Назначение

Проект `geometry_lib` предназначен для вычисления площади и периметра геометрических фигур с использованием языка C++.

## Реализованные возможности

На текущем этапе реализованы следующие функции:

- `SquareArea(double side)` — вычисляет площадь квадрата.
- `SquarePerimeter(double side)` — вычисляет периметр квадрата.
- `RectangleArea(double length, double width)` — вычисляет площадь прямоугольника.
- `RectanglePerimeter(double length, double width)` — вычисляет периметр прямоугольника.

## Используемые формулы

Для квадрата со стороной `a`:

- Площадь: `S = a * a`.
- Периметр: `P = 4 * a`.

Для прямоугольника со сторонами `a` и `b`:

- Площадь: `S = a * b`.
- Периметр: `P = 2 * (a + b)`.

- `main.cpp` — основная программа.

- `README.md` — главная страница проекта.
