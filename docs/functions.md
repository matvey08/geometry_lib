# Описание функций

## 1. SquareArea
Вычисляет площадь квадрата по длине его стороны.

Параметр: `side` — длина стороны квадрата.
Возвращаемое значение: площадь квадрата.

Пример:
`SquareArea(4.0)` возвращает `16.0`.

## 2. SquarePerimeter
Вычисляет периметр квадрата по длине его стороны.

Параметр: `side` — длина стороны квадрата.
Возвращаемое значение: периметр квадрата.

Пример:
`SquarePerimeter(4.0)` возвращает `16.0`.

## 3. RectangleArea
Вычисляет площадь прямоугольника по длине и ширине.

Параметры:
- `length` — длина прямоугольника.
- `width` — ширина прямоугольника.

Возвращаемое значение: площадь прямоугольника.

Пример:
`RectangleArea(3.0, 5.0)` возвращает `15.0`.

## 4. RectanglePerimeter
Вычисляет периметр прямоугольника по длине и ширине.

Параметры:
- `length` — длина прямоугольника.
- `width` — ширина прямоугольника.

Возвращаемое значение: периметр прямоугольника.

Пример:
`RectanglePerimeter(3.0, 5.0)` возвращает `16.0`.
