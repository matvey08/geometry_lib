# geometry_lib

Библиотека на C++ для вычисления площади и периметра квадрата и прямоугольника.

## Возможности

- `SquareArea(side)` — вычисление площади квадрата.
- `SquarePerimeter(side)` — вычисление периметра квадрата.
- `RectangleArea(length, width)` — вычисление площади прямоугольника.
- `RectanglePerimeter(length, width)` — вычисление периметра прямоугольника.

## Пример использования

- `SquareArea(4.0)` возвращает `16.0`.
- `SquarePerimeter(4.0)` возвращает `16.0`.
- `RectangleArea(3.0, 5.0)` возвращает `15.0`.
- `RectanglePerimeter(3.0, 5.0)` возвращает `16.0`.
